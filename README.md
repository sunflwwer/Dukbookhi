# 덕북희 (Dukbookhi)

"덕우들을 위한 부킹" — **강의실 예약 & 교수님 상담 예약 웹 서비스**입니다.

## 🎯 프로젝트 소개

학생들은 강의실 대여를 간편하게 신청하고 교수님께 상담을 요청할 수 있으며, 교수님은 캘린더를 통해 스케줄을 손쉽게 관리하고 학생들의 상담 요청을 확인할 수 있는 웹 플랫폼입니다.

* **팀원 구성**: Frontend 1명, Backend 3명
* **진행 방식**:
  * GitHub를 활용한 코드 관리 (Fork 후 개인 레포 생성 ➔ 공동 레포 PR 및 Merge)
  * 주 1회 대면 회의 진행 (회의록 및 진행 상황은 Notion에 기록)
  * 개발 진행 상황은 카카오톡을 통해 실시간 공유

## 👩🏻‍💻 담당 역할

프론트엔드 담당으로 참여하여 웹 서비스의 UI/UX 구현 및 프론트엔드 전반을 개발했습니다.

* **구현 페이지 및 요소**:
  * 대표 페이지 및 로그인 페이지
  * 학생 / 교수자 메인 페이지 및 마이페이지
  * 강의동 & 층 선택 페이지 / 강의실 선택 페이지
  * 단과대 & 학과 선택 페이지 / 교수님 선택 페이지
  * Navbar, Footer 및 이너 페이지 전반

## 🖥️ 사용 기술

- HTML, CSS, JavaScript
- Django

## 🌱 성장 경험

- **Git 기반 팀 협업 습득**: 단순히 `git push`로 스터디 자료를 올려보던 방식에서 벗어나, Fork 및 PR/Merge 과정을 통한 본격적인 Git 협업 워크플로우를 경험했습니다.
- **동적 UI 및 UX 구현**: 화면 상태에 따라 동적으로 변화하는 UI와 흥미를 유발하는 애니메이션 효과를 구현하며 사용자 경험(UX) 중심의 개발을 고민했습니다.
- **프론트엔드 전담 경험**: 프론트엔드 전반을 직접 담당하며 수업에서 배운 HTML, CSS, JS 지식을 실제 서비스 개발에 완성도 있게 적용해보는 계기가 되었습니다.
